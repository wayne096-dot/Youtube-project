# 📺 YouTube Termux Player

A lightweight YouTube video/live stream player designed specifically for the **Android Termux** environment.

It integrates an `SDL2` graphical interface, the `mpv` playback engine, `pytchat` for live chat, and `yt-dlp` for threaded comment parsing.

It can play YouTube videos even under severe bandwidth limits (as low as **15 KB/s**) at **144p**.

---

## ✨ Features

* 🎬 **Video & Live Stream Playback**
  * Supports both regular YouTube videos and live streams (powered by `mpv` and `yt-dlp`).

* 💬 **Real-Time Live Chat**
  * Displays live chat messages in real time.
  * **Smart Auto-Scroll**
    * Press `↑` / `↓` to browse chat history, which temporarily disables auto-follow.
    * After **10 seconds** of inactivity, the player automatically returns to the latest message and resumes following the chat.

* 🌳 **Threaded Video Comments**
  * Fully supports expanding and collapsing nested replies (`Enter` key).
  * Displays like counts and relative timestamps (e.g. `5 minutes ago`, `2 weeks ago`).
  * Supports loading additional comment pages.

* ⚡ **Optimized for Termux**
  * Automatically uses the `deno` JavaScript runtime to improve `yt-dlp` parsing performance.

# 📱 Termux Installation Guide

To run this project in Termux, install the C/C++ toolchain, SDL2 libraries, and the required Python dependencies.

## Step 1: Update Packages and Install System Dependencies

Open Termux and run:

```bash
# Update packages
pkg update && pkg upgrade -y

# Install required tools, compiler, and playback components
pkg install python clang ffmpeg mpv mpv-x libsdl2 libsdl2-ttf libsdl2-image deno pkg-config -y
```

> **Note:** `deno` provides the JavaScript runtime required by `yt-dlp` to decrypt YouTube JavaScript.

## Step 2: Install Python Dependencies

Upgrade the build tools:

```bash
pip install --upgrade pip setuptools wheel
```

Install the required Python packages:

```bash
pip install yt-dlp pytchat PySDL2 python-mpv
```

# 📝 Troubleshooting

### `yt-dlp` comment retrieval is slow or fails

- Make sure `deno` is installed:

  ```bash
  pkg install deno
  ```

- `youtube.py` automatically uses `deno` as the JavaScript runtime to speed up parsing.

- Keep `yt-dlp` up to date:

  ```bash
  pip install -U yt-dlp
  ```

### `[vo/x11] Warning...` appears on screen

This is a normal warning generated by the Termux X11 / GUI rendering environment and does **not** affect video playback or comment rendering.
